# Research OS

Unified research and knowledge-intelligence infrastructure for all Worldwidebro ventures, VEX, and integrated tools.

## Core Loop

Question -> Search -> Sources -> Evidence -> Claims -> Synthesis -> Hypothesis -> Experiment -> Result -> Decision -> New Question

## Integrated Systems

- VEX: Public brand and venture registry
- Obsidian: Human research interface
- Apple Notes: Mobile capture
- Notebook LM: Document synthesis
- Neo4j: Relationship layer
- Qdrant: Semantic retrieval
- GitHub: Version control and research tasks

## Principles

- Evidence before conclusion
- Provenance before trust
- Uncertainty before certainty
- Reproduction before confidence
- Questions before documents
- Contradiction before confirmation
- Version everything
