# Research OS

Reproducible research and knowledge-intelligence infrastructure for humans and AI agents.

## Core Loop

Question -> Search -> Sources -> Evidence -> Claims -> Synthesis -> Hypothesis -> Experiment -> Result -> Decision -> New Question

## Architecture

Markdown -> Structured Data -> Knowledge Graph -> Semantic Retrieval -> Agents -> Evaluation -> Human Review

## Principles

- Evidence before conclusion
- Provenance before trust
- Uncertainty before certainty
- Reproduction before confidence
- Questions before documents
- Contradiction before confirmation
- Version everything
